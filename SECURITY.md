# Security Policy

## Supported versions

This repository is currently maintained on the default branch only.
Security fixes are applied to the latest code.

## Reporting a vulnerability

Please do not open public issues for sensitive vulnerabilities.

Report privately by contacting the maintainers with:

- Vulnerability description
- Impact assessment
- Reproduction steps
- Suggested remediation if available

You can expect an initial response within 5 business days.

## Data and privacy notes

This project is designed to avoid storing raw patient audio.
Only derived acoustic features are processed in the main pipeline.

For real-audio experiments, ensure your dataset usage complies with:

- Dataset license terms
- Applicable privacy regulations
- Institutional review requirements where applicable
