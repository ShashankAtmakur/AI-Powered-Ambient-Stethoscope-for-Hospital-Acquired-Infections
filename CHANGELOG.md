# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project follows Semantic Versioning.

## [1.0.0] - 2026-04-01

### Added
- Multi-disease room simulation scenarios (pneumonia-like, URI-like, sleep-apnea-like).
- Real-audio manifest builder and training pipeline integration.
- Patient-only respiratory sound extraction workflow in scripts and dashboard.
- Publish-ready repository assets: CI, pyproject, contributor and security docs.

### Changed
- ACK API path compatibility improved for payload and payload-less calls.
- README expanded with release checklist, quality gate, and dataset guidance.
